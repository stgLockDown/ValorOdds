# Outreach toolkit

Copy-ready templates and playbooks for the off-site SEO / link-building /
PR work that sits outside the Next.js app. Each file is designed to be
dropped straight into an email, a pitch deck, or a content brief with
minimal editing.

## What's here

| File | Use |
|------|-----|
| `press-release-launch.md` | Standard newswire-ready press release for a launch / major feature announcement. |
| `pitch-journalists.md` | Cold-outreach email templates for sports-business reporters (Legal Sports Report, Covers, EGR, SBC Americas). |
| `pitch-podcasters.md` | Cold-outreach templates for betting podcasters (sponsorship + guest pitches). |
| `pitch-affiliates.md` | Cold-outreach templates for affiliate sites and content creators. |
| `data-journalism-briefs.md` | Data-led story briefs we can pitch to reporters. Each is a "hook + CSV + chart" package. |
| `link-building-playbook.md` | 90-day playbook: what to do in week 1, month 1, quarter 1. |
| `directory-submissions.md` | List of quality directories where we should be listed. |

## General rules

- **Every external mention should link to a canonical URL.** Use
  `https://valorodds.com/[path]?utm_source=<source>&utm_medium=<medium>&utm_campaign=<campaign>`
  with UTMs. The UTMs are for our attribution — Google reads these as the
  same URL for link-equity purposes.
- **Attribute every data point.** Stats we share publicly should be tied
  to an internal data export. If we're going to say "average edge was
  3.2% in Q2 2025", someone on the team should be able to produce the
  CSV on demand.
- **Responsible-gambling language on every outbound asset.** "21+" and
  "gamble responsibly" disclaimers at minimum. This keeps us eligible
  for coverage in jurisdictions where the topic is restricted.
- **Never purchase links.** No paid placements, no link farms, no PBNs.
  Everything here is editorial or earned.
